# ivo_devlpmt

Portfolio de desarrollo web y sistemas a medida.

## Correr en local

    npm install
    npm run dev

## Agregar capturas de un proyecto

1. Copiar las imágenes a `public/img/<proyecto>/`.
2. En `src/datos/proyectos.js`, completar `imagenes` del proyecto:

        imagenes: [{ src: '/img/crm/panel.png', alt: 'Panel principal' }]

## Publicar

Importar el repositorio en Vercel (Framework: Vite).
